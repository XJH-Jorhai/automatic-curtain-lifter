# 固定电流 TRQ 采样 v8（2026-10-25）

本构建用于验证现有硬件能否在同一速度、电流下区分正常运动和端点。用户选择继续尝试纯软件方案，未更换R6。v7在原电流360 rpm的一次真实到顶中已触发端点，但延迟约0.9秒；v8调整滤波及相对门槛后，用户确认上端明显变快至约0.1–0.2秒，下端反卷后也很快自动停，RAM记录均与之吻合。通用自动方向识别仍未验证。详见[v8现场记录](../../hardware/test-records/2026-10-25-trq-filter-v8.md)。

用户已确认原试探第一段DIR=0为上卷，第二段DIR=1为下放。采样版固定使用此方向，启动忽略原行程，第一次拨动的开关触点仍定义为上；该映射和端点仅存RAM。`mode=1 capture=1`代表本次人工确认的方向已就绪，不代表自动识别成功或已保存。

## 本次参数与操作

- 上下均名义360 rpm、9600 STEP/s，原约1.50 A档贯穿起步和运行，不切0.42 A；电流为VREF换算，非绕组实测。
- 保持1秒加速、150 ms稳定等待；之后5个5 ms采样取中位数，连续80 ms低于 `max(64, 本段健康基线×50%)` 判为失速。基线也使用中位数，健康最低ADC128。原始ADC>=4080持续50 ms仍直接报错，不受滤波掩盖。
- 本地按住运行、松手立即停止；同时按上下、nFAULT、ADC失败、主循环250 ms失活和单段120秒等保护保留。App运动请求拒绝，STOP仍可用。
- 不执行两段试探。用户按住已定义的上侧，到真实顶部观察是否自动停止；若实际失步后约0.2–0.3秒仍未停，松手结束，随后只读提取RAM采样。
- 原B1开机旋律和工作电流、正反各5微步保留。

采样按5 ms维护原始值总数和极值，最近工作段保留160个10 ms时间戳/ADC点，约1.6秒。槽2为最新工作段；复用空闲的探测槽0/1分别保留最近上/下自动停机的轨迹，后续手动短拨不会覆盖快照。停止后读取，无自动串口采样流。M的 `trq` 是原始值，`trqf` 是判定使用的中位数；采样模式中 `probe` 对应上述两个快照，不能当作已执行两段方向试探。

EEPROM在启动时读取两个行程槽及两个乐谱槽，动作期间不读写。采样构建的ELF不含 `Eeprom_Update`、`Eeprom_UpdateLiftRecord`、`Eeprom_WriteScoreSlot` 或 `Music_SaveScore`，原方向记录和音乐槽均不修改。学习结果不会跨重启保留。

## 构建与部署

```powershell
.\firmware\g030_mainboard\build.ps1 -Configuration TrqCapture
.\firmware\g030_mainboard\test_product.ps1
```

输出位于 `work/g030-mainboard-build/TrqCapture/`；独立预设启用 `TRQ_CAPTURE_ONLY=ON` 和 `TRQ_CAPTURE_UP_REVERSE=0`。默认 `Product` 明确关闭采样开关。两种构建均已编译，主机回归通过。除原有合成ADC测试，新增v7真实保留波形10 ms回放，4种先前基线均在明显下降后110 ms停止，无此前正常点误判；回放不重建未保留的5 ms点。

本次冻结文件位于 `work/releases/2026-10-25-trq-filter-v8/`。BIN27052字节，RAM5528字节；BIN SHA256 `2219e0835dd857588d6df44598324e97d6e42e499437d757966d7fc903501804`。

沿 `flash_bounded.py` 浮条入口，以50 kHz SWD、4字块完成烧录、完整读回、选项字核对及复位运行。启动检查CPU运行、GPIO禁能休眠、B1完成3340脉冲净偏移0、UART错误0、行程读取2/保存0，状态 `map=0 mode=1 saved=0 low=0 capture=1`。

只读检查脚本为 `work/read_motion_observation.py`，需匹配冻结ELF。`--capture-startup`仅用于尚未操作开关的启动检查；现场运行后去掉此选项，用 `--trace-out`提取RAM。脚本只读SWD并发送M查询，不复位、不暂停、不发运动命令。原 `product_status.py` 的未知方向启动断言不适用于此构建。

v8单次实板上端记录为 `result=2/error=0`、baseline223、原始末值116/滤波35，最后有效点1441 ms，首次明显低值约1351 ms；与用户0.1–0.2秒自动停止的观察对应。下端亦为 `result=2/error=0`，baseline278、原始67/滤波79，首次明显低值26789 ms，停机约26879 ms。RAM行程估计250585微步，两个端点及当前位置可信。
