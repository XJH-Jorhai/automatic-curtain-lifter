## EEPROM寿命保护

**EEPROM必须按需读写，禁止任何定时、周期、循环扫描或重复周期读写。** 已删除后台读取服务及其主循环调用。新增的启动播放事件只加载一次双槽，不写入；其他访问仅来自明确的业务或诊断事件。`music.h` 提供保存乐谱、获取乐谱、播放及停止接口，详见 [MOTOR_MUSIC.md](MOTOR_MUSIC.md)。加载后使用RAM缓存；相同乐谱重复保存零I2C访问。

没有擦除/填充/全片写入API，串口原始`EE W`入口已关闭，旧主机全片写读恢复功能已移除。即使读操作不消耗编程寿命，也不得因此恢复周期读取。

单页更新接口`Eeprom_Update`及乐谱专用`Eeprom_WriteScoreSlot`均仅按需调用：

- 单次1–16字节且必须在同一物理页；拒绝跨页、越界及大块请求。
- 先比较，相同数据直接成功，不发编程事务；不同数据仅发送首尾差异范围。
- 全局60秒逻辑保存冷却，每次上电最多8次尝试，失败/不确定的写入也计入预算，不自动重试。乐谱专用接口一次最多14个物理页写，限定在0x000/0x100的双槽，最后提交校验头；单页接口仍限制1–16字节。
- ACK轮询结束后回读校验。计数在RAM，不能作为跨复位寿命账本；未来高频位置存储需独立的CRC/序号、多槽轮转和掉电一致性设计。

`EE TEST`同时运行RAM模拟I2C后端策略测试和实片同值更新检查。模拟测试复用生产实现，覆盖全片/跨页/越界拒绝、同值跳过、60秒冷却、tick回绕、失败计入预算和8次上限；它不会向实片写入图案。

## 串口命令

音乐模式已改为**每个微步自动正反交替**，正常每音结束完成正反一对；支持直接输入`c4f4g4`。
先用`CHECK c4f4g4`无动作检查，`PLAY c4f4g4`或直接音符文本播放一次，`STOP`随时停止。
详见[音符语法、正反策略及硬件细分限制](MOTOR_MUSIC.md)。M0/M1硬接DVDD，软件不能关闭1/8细分/切到整步。

| 命令 | 行为 |
|---|---|
| `PING <标记>` / `UART` | 回显 / UART错误、缓冲溢出计数 |
| `LED ON` / `LED OFF` | LED GPIO控制及ODR/IDR回读 |
| `INPUTS` / `ADC` | 静态输入 / 四路模拟采样，外部值未标定 |
| `EE SCAN` / `EE R <地址>` | 八个地址块ACK / 读取16字节 |
| `EE STATUS` | RAM中的读取事务、探测、错误、写入统计；查询不访问EEPROM |
| `EE TEST` | 无物理写入的策略自测 |
| `MOTOR STATUS` | phase、命令步数、停止原因、方向及控制脚IDR |
| `MOTOR TUNE` | 保留的第一乐句，使用自动正反交替 |
| `CHECK <音符>` / `TUNE TEST` | 仅解析 / 无运动自测 |
| `PLAY <音符>` / 直接`c4f4g4` | 单次播放，支持节拍、时值、升降号及休止符 |
| `MOTOR RUN F` / `MOTOR RUN R` | 固定400步、50→2667Hz渐进启动、约1.50A满量程、约0.54秒限步诊断；不得连接执行器测试 |
| `STOP` | 立即禁用、休眠、STEP/DIR/电流选择回低 |
| `MOTOR TEST` / `MOTOR IO` | 内存逻辑自测 / 禁用时STEP/DIR回读，不用于判断转子正常 |

运行中只接受STOP、STATUS、ADC、INPUTS、EE STATUS及PING/UART，不接受新运动和维护操作。
phase：0空闲、1唤醒、2使能等待、3运行、4故障。reason：0启动/无结束、1完成、2故障、3总超时、4显式停止、5主循环超时。
