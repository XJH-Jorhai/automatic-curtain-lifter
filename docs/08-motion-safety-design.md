# 下一阶段：卷帘运动与位置设计基线（草案 v0.8）

> 2026-10-22：用户本次更新的360rpm方向试探、上下边界识别及1–99%未知位置动画已实现到 [Product固件](../firmware/g030_mainboard/PRODUCT.md)。以下为早期设计；当前代码行为、构建与验证以产品文档为准，实际机构尚未接入。

## 1. 当前进度与本阶段出口

2026-09-25 的真实台架只证明 G030C8T6、T1-3S、涂鸦 App 之间的联网和 DP 往返。现有固件拒绝运动 DP1，DP2 仅把目标存入 RAM，DP101 恒为 0；它没有电机输出、限位、按键或位置保持。详见[联调记录](../hardware/test-records/2026-09-25-g030-t1-3s-live.md)和[现有代码](../firmware/g030_tuya/App/bridge.c)。

**下一步工作是完成卷帘运动、上端回零和位置估算设计。** 对象是拉珠式竖向卷帘。用户实物检查发现：升到顶有机械限位；拉珠移动超过一整圈；放到底没有限位，但帘布越过最低点、重新卷起时有明显顿挫。设备之外不改动窗帘或窗框，不加额外开关，也不采用黑珠检测。开发板接真实电机不是本阶段的前置条件；但低力矩上行触顶的受力、失速判据、下端顿挫的电气特征及真实最低点偏移，必须在真实电机和卷帘上验证。

本阶段出口：确定上端回零的检测路线、自主下端检测及设备内反馈扩展的接口预算；评审状态机、位置可信度与持久化规则；无电机时可验证纯逻辑。按[电机选型决策](09-motor-drive-decision.md)先以步进电机的 STEP/DIR 路线设计，直流减速作为备选；检测阈值、速度及力矩只能在真实机构上定值。

## 2. 机构假设与位置反馈选择

拉珠驱动的具体离合、弹簧和平衡结构尚未拆解。实物确认的**上端机械限位**是可重复的位置基准候选；**下端反卷顿挫**是可检测的机械事件候选。能用手感到顿挫，不等于 MCU 已有可用的电信号：要测它在不同速度、帘布重量和供电条件下的信号幅度与重复性。拉珠超过一整圈，单颗黑珠会重复经过探头，无法在失去圈数后唯一确定全行程位置，因此不再列为首版基准。

**先确认断电静止能力：** 电机不提供保持力时，原有拉珠机构能否在任意中间位置保持帘布不自行滑动。若不能，位置会在 MCU 不知情时变化；持续给电机通电保持位置又可能使联网静息 `<100 mW` 目标无法实现。此时必须重新评估机械制动/自锁、反馈或功耗指标，不能只增加 EEPROM 写入频率。

**上端回零使用原有机械限位：** 以经实测可带动卷帘的低电流、可检测失速的低速和最大行程边界向上运行；DRV8434A 扭矩计数失速作为候选触顶，再以下端事件、行程合理性和第二次触顶复核。首次未知位置的失速仍无法从原理上区分途中卡住和真正到顶；用户接受中途卡住概率很低的取舍，但必须通过卡阻注入与峰值力试验确认可接受风险。所有运动均限制力矩、时间和最大步数。

步进电机是首选，首块样机候选为 42CM02-1A + DRV8434ARGER 裸芯片，具体[接口和端点检测设计](11-stepper-interface-endpoint-detection.md)已列出。常见步进驱动器调节绕组电流，不能简单用“电流突然变大”判断堵转；原候选 [DRV8424](https://www.ti.com/product/DRV8424) 的 `nFAULT` 覆盖欠压、过流、过热等电气保护，不是到位信号。DRV8434A 的扭矩计数/失速检测可供 MCU 判断，但低速回零的检测余量须实测。直流减速电机只作备选；它的堵转电流上升较容易观察，但启动冲击电流也高，需要区分。[TI 步进堵转检测说明](https://www.ti.com/lit/an/slvaei3a/slvaei3a.pdf)。

上端定义为 `100%` 基准。无有效行程时，第一次收到 `0%` 或 `100%` 命令便自主进入双端校准：先找到上端候选点，再向下检测最低点，复测上端和下端后保存软件行程，最后回到所请求端点。无需人工点动、监督或确认，也无需显式校准按钮；可保留可选的重新校准入口。下端先验证反卷顿挫的电信号及与真实最低点的偏移；若不可靠，只在设备内部增加张力或链轮运动反馈。普通下放依已存行程停下，不故意反卷。具体状态机和失败边界见[芯片接口与端点检测设计](11-stepper-interface-endpoint-detection.md)。

两点间初始 `0–100%` 表示**标定运动量区间的比例**，不是已证实的帘布垂下高度比例；卷布半径变化会使两者不完全线性。若需要按真实高度显示百分比，可在样机上测量并增加分段校准表。商用卷帘通过用户设定上下位置的操作可作为交互参考，但不能据此假定本机构有同样的内部反馈。[Somfy 卷帘端点设置说明](https://www.somfypro.com/support/faq?question=how-to-adjust-the-upper-and-lower-position-of-motorized-roller-and-solar-shades)。

步进脉冲计数只说明发出了多少步；直流电机的编码器或电流纹波计数只说明测得的电机运动，两者都不能单独证明拉珠与帘布没有相对滑动。首版以“估算位置”定义 DP101，失去可信度后通过受控上端回零恢复。单圈绝对角度传感器只提供一圈内的角度，卷筒转多圈后仍无法单独确定总行程；要在任意断电位置读出绝对位置，需多圈绝对测量或直接测帘布位置。[TI 单圈绝对编码器设计](https://www.ti.com/tool/TIDA-010947)。

## 3. 已确定的控制边界

| 输入或状态 | 必须执行的行为 |
|---|---|
| 上电、复位、看门狗复位 | 驱动硬件默认关闭；不恢复上次运动；载入有效记录后仍保持停止。上次记录为运动中或记录损坏时，位置标为不可信。 |
| 任意来源 `stop`、本地开关松手回中位 | 先停止产生运动命令，再关闭驱动；保存最终位置和停止原因；上报一致快照。停止优先于新目标。 |
| 到达下端软件行程 | 停止继续向下运动；反向命令可正常执行。正常下放不靠顿挫寻找端点。 |
| 上端回零 | 只在受控校准流程中低速接近机械限位；可靠确认后重置位置计数，未确认则保持位置不可信。 |
| 驱动故障（含芯片报告的欠压）、运行超时 | 停止电机并记录原因；不得无提示地继续上次目标。这里是基本电气保护，不要求独立急停装置。 |
| 尚未标定、位置不可信 | 首次 0%/100% 命令自动进入双端校准；其他百分比暂缓。已有有效行程但位置不可信时，下次定位命令先自动上端回零。失败则报告故障，不保存猜测值。 |
| 网络断开 | 本地控制和安全判断继续；重连后上报当前快照，不重放过期的网络运动命令。 |

`continue` 仅恢复本次上电、被明确 `stop` 中断且目标和位置仍可信的动作；故障、复位及校准状态都清除可恢复目标。位置是按相对运动量估算，不能证明传动没有失步或打滑。校准失效时不应继续上报貌似可信的绝对百分比；现有涂鸦 DP 没有可信度字段，需要在面板语义或后续 DP 设计中解决。

优先级从高到低：硬件失电/复位默认态 → 驱动故障/供电异常 → 停止 → 软件行程端点 → 自主校准 → 新的 App/按键目标。中断只锁存故障与停止输出，不做 UART 上报或 EEPROM 写入；主循环负责持久化和状态通知。

## 4. 状态机与平台接口

建议状态：`UNTRUSTED`、`IDLE`、`MOVING_OPEN`、`MOVING_CLOSE`、`CALIBRATING`、`FAULT_LOCKED`。任何运动状态只能由单一运动层控制电机输出；涂鸦 DP、按键和未来米家适配层都提交同一种命令。状态迁移先校验软件行程、可信度和故障，再改变目标。接受命令不等于运动完成，DP2 目标与 DP101 当前位置必须分开上报。

| 接口 | 最小内容 |
|---|---|
| `motion_command` | 来源、命令类型、目标百分比/点动方向、接收时序号；拒绝时返回原因。 |
| `motion_snapshot` | 状态、目标、相对位置计数/百分比、位置可信度、软件端点、故障、是否正在校准。 |
| `motion_input` | 驱动故障、钮子开关两路输入、驱动扭矩计数；可扩展设备内张力/链轮运动反馈。没有 MCU 12 V 模拟电压检测输入。 |
| `motion_output` | 平台无关的方向、速度、使能与停止；底层适配 STEP/DIR 或 PWM/H 桥。 |
| `storage_record` | magic、版本、序号、行程端点、最近安全停机位置、方向、CRC；EEPROM 多槽轮转记录。上电位置可信度先置为不可信。 |

运行策略先选保守的加减速与超时上限，速度、加速度、电流和最长行程全部保持可配置，待目标电机与机械负载确定后定值。普通停止命令应及时停止电机输出，不能等待较慢的网络或显示任务。软件行程外须留适当安装与误差余量，具体数值靠样机确定。

## 5. 原理图接口预算，暂不指定 MCU 物理引脚

| 功能 | MCU 资源 | 设计要求 |
|---|---:|---|
| T1-3S UART | 2 GPIO + 1 USART | 现台架用 PA9/PA10；保留独立调试串口仅用于研发版。 |
| 电机输出 | 定时器 + 方向/使能引脚，数量待选型 | 步进为 STEP/DIR/休眠；直流减速为 PWM/方向/H 桥使能。复位默认断开功率输出。 |
| 驱动故障/到位 | nFAULT 数字输入 + 扭矩计数 ADC | 失速是候选端点信号；电气故障后软件锁定。 |
| 双向复位钮子开关 | 2 输入 | PC6=`KEY_UP`、PC7=`KEY_DOWN`，低有效；中位停止本次本地运动。实体拨向由装板后测试映射。 |
| 独立配网键 | 1 输入 | PC13=`NETCONTROL_BTN`，低有效；原独立 STOP 键已删除。 |
| EEPROM | 2 GPIO + 1 I²C | 与运动计时资源分离；轮转记录写入。 |
| SWD/复位 | SWD 2 + NRST | 研发与量产测试均保留可接触测试点。 |
| 位置检测 | STEP 计数、DRV8434A 扭矩计数和 U7 扩展 | 步进先使用命令步数；下端须用真实机构验证扭矩计数与帘布最低点的关系。PA1 的 12 V ADC 检测已删除。 |

首版固定 STM32G030C8T6。现有 G030 Debug 台架固件已用 21,684 B Flash、2,256 B 静态 RAM，且尚无运动、存储、张力采样和按键代码；这些数字不能证明最终 Flash/RAM 和最坏栈仍有余量。固件加入全部功能后核算资源，并用 CubeMX 审查当前 LQFP48 的逐脚复用。

原理图须先依据[电机选型决策](09-motor-drive-decision.md)确定步进或直流减速路线，再核对所选驱动的电流、控制与反馈接口、故障行为和休眠状态，并保留波形测量点。DRV8424 没有明确的堵转到位输出，不能仅凭它的 `nFAULT` 冻结上端回零设计。[TI DRV8424 数据手册](https://www.ti.com/lit/ds/symlink/drv8424.pdf)。

## 6. 验证顺序

1. **协议快照对齐：** 重新下载 DP2 步长为 1 的 XLS、协议和生成 SDK，与当前 JSON 逐项比对；保留旧快照供溯源。
2. **机构与输出需求：** 先验证电机不提供保持力时卷帘在上、中、下位置能否稳定停住；用弹簧秤测拉珠力、链轮半径和期望开合时间，记录上端限位的接触行为及下端反卷顿挫。黑珠因拉珠超过一圈不作为唯一基准。详见[电机选型决策](09-motor-drive-decision.md)。
3. **纯逻辑验证：** 给运动层输入未标定、上端候选失速/超时/误检、自动检测下端、重复性检查、下端软件行程、顿挫事件或设备内反馈、正常命令、停止、nFAULT、驱动欠压故障、外部供电跌落、异常上电、网络重连和 `continue`；检查状态机、拒绝原因、步数边界及上报快照。用模拟时钟覆盖加减速和超时，不需电机驱动板。
4. **持久化验证：** 模拟 轮转记录写入中断、CRC 损坏、序号回绕和“运动中断电”；检查启动不自启、可信度清除、下一次命令自动找基准或重测行程。
5. **G030 波形验证：** 选定电机类型后，在不连接功率级时核对对应 STEP/DIR 或 PWM/方向/使能信号，检查复位、普通停止、换向、下端软件行程、模拟上端到位和驱动故障下的电平与时序。
6. **真实机构检测验证：** 用首轮候选电机和驱动，在上端接触、正常中途负载、人为模拟途中卡阻、下端顿挫四种情形同步捕捉扭矩计数、拉珠峰值力和位置估算信号，并核对丢步、噪声和温升。样机还须记录下端事件与真实最低点的偏移；若扭矩计数无法稳定检测，研究设备内链轮运动反馈或机构变化。若步进路线的关键指标无法满足，再启用直流减速备选。该项放在首板样机阶段，量产参数定板前完成。
7. **资源与电源设计：** G030C8T6 的 CubeMX 逐脚复用审查、完整固件尺寸/栈预算；确定目标电机与适配器规格后计算驱动电流、Buck 峰值、VM 电容和热路径。联网静息 `<100 mW` 仍需实测，当前没有合格数据。

真实电机验证可在样机阶段进行，但在带负载使用或宣布行程安全、扭矩、噪声、热性能合格前必须完成。原理图可先画可评审草图；器件数值、PCB 散热和整机性能不能在机械与电机参数缺失时冻结。
