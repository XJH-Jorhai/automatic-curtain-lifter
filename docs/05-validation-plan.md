# 验证计划与待确认事项

## 当前状态（2026-09-25）

- 米家正式 Gate 0：因无公司主体仍受阻，保留未来企业/服务商合作路线。
- 涂鸦个人 Gate：已通过实名认证并创建窗帘开关产品，已选公版面板、T1-3S 和直连固件，已下载 DP/协议/SDK/规格书。
- DP 2 `percent_control` 已修正为 1% 步长，新调试 JSON 已核验。XLS、产品协议和 MCU SDK 仍须重新生成并与新 JSON 比对；现有 G030 台架固件已显式处理整数 0–100。
- T1-3S 已完成 `t1_common_user_config_ty` 3.0.22 烧录授权；真实 STM32G030C8T6 + T1-3S 台架已完成串口、AP 配网、云端在线、App 百分比下发与状态回传。见[2026-09-25 实测记录](../hardware/test-records/2026-09-25-g030-t1-3s-live.md)。
- 电机、自主双端校准、下端软件行程、按键、EEPROM、掉电重连、BLE 配网与功耗尚未验证。目标为竖向拉珠式卷帘：上端有机械限位，下端无止动但反卷有顿挫；拉珠超过一圈，单颗黑珠不作为唯一位置基准。首版主控已定 STM32G030C8T6，涂鸦先行。
- 协议与 SDK 来源见[涂鸦 T1-3S 接入基线](07-tuya-t1-3s-integration-baseline.md)。

## Gate 0：先验证接入资格（立即进行）

具体步骤、工单正文和逐项回馈要求见米家开发权限 Gate 0 完整操作手册（历史附件未随公开候选提供）。

1. 用计划持有产品的中国大陆企业主体注册/加入小米 IoT 企业开发组，并完成品牌审核。
2. 在 `iot.mi.com` 的创建产品页核对“个护与起居 / 卷帘电机”的联网和开发方式选项；在获得确认前不提交不可更改的联网方式和型号。
3. 提“产品方案与流程咨询 - 新品开发”工单，书面确认“卷帘电机 + WiFi+BLE 通用模组 + STM32 MCU/UART”组合、准入/MOQ、协议/工具、设备身份、面板、测试、费用和周期。
4. 组合确认后再创建 product model，并申请当前推荐 Wi-Fi+BLE 通用模组、MCU 协议/工具、测试环境和样品。

**通过标准：** 获得书面许可或后台权限，确认应用可访问所选电机控制所需的 GPIO、定时器/PWM、I²C、NVS 和 Wi-Fi 低功耗接口。若两周仍无法取得，启动标准模组+MCU询价，同时保留 Matter PoC，但不做正式 PCB 定板。

**个人开发分支：** 若当前没有中国大陆公司主体，正式米家 Gate 0 记为“受阻但不终止项目”。继续当前 G030 + 涂鸦模组 PoC；未来取得合规企业合作后再实现 `platform_miot`，不得冒用其他产品 model 或设备身份。

**涂鸦中间验证：** G030 台架已完成 AP 配网、窗帘 DP、App 面板和云端状态同步，见[真实联调记录](../hardware/test-records/2026-09-25-g030-t1-3s-live.md)；断网恢复仍待测试。该结果不替代米家准入、SDK、面板、设备身份和功耗验证。

## Gate 1：开发板 PoC

- 当前 STM32G030C8T6 开发板 + T1-3S 已完成无电机协议与云端台架。本阶段先按[卷帘运动与位置设计基线](08-motion-safety-design.md)完成平台无关运动逻辑、异常状态模拟、G030 输出波形和 MCU 资源审查。开发板接真实电机不是进入首块原理图和 PCB 样机设计的前置条件；首板使用 DRV8434A 扭矩计数验证上端低力矩失速及下端反卷顿挫，不装窗帘端点开关、HX711 或应变桥。
- 无电机协议 Gate 已完成：心跳、产品信息、Wi-Fi 状态、DP 下发、安全拒绝、全量查询和 App 状态回传。DP101 目前固定为 0，不能视为实际位置验证。
- 生成 SDK 中的 `#error`、空 DP 处理器和无条件回显必须全部替换；命令只有通过运动层安全检查后才能上报为已接受状态。
- **自主校准逻辑验收：** 清空 EEPROM 后分别发送首次 0% 和首次 100%，用模拟扭矩计数、下端事件及 STEP 计数核对两次上端候选触顶、两次下端一致性、轮转记录与 CRC 校验和最终目标；模拟途中卡阻、下端误检/漏检、STOP、掉电和重启，失败时不得写入有效行程或要求用户点动。该验证不需开发板接实际电机。
- **EEPROM 写入验收：** 测校准成功及受控停机写入、分页边界、写后校验、断电打断写入和旧记录回退；运动中不周期性写入。任意时刻复位后位置先不可信，下次命令回零。按预计每日动作次数和轮转槽数核算十年内每页写入次数。
- 先确认电机断电后卷帘能否稳定停住、上端机械限位能承受怎样的低速接触。用户已提供 0.75–0.85 kgf 拉力、6 mm 珠距和局部位移数据，见[实测与置信度](10-curtain-measurement-estimate.md)；下一步量链轮每圈经过的珠数和上/中/下位置的拉力，优先验证步进路线。设计首次 0%/100% 自主双端校准、软件行程、百分比换算、加减速、EEPROM 轮转记录和异常上电逻辑。下端顿挫是首选自动检测候选；若电气信号或最低点偏移不可靠，研究设备内张力/链轮运动反馈，仍不改装窗帘。
- 用可编程电源模拟 12 V 瞬断、跌落和反复上电；验证不丢配置、不误动作。
- 用实物 U6 核对拨上/拨下各使 1-2 或 2-3 哪组触点导通，并据此配置 PC6/PC7 上下行映射；验证中位自动复位、两路输入电平、消抖、松手停止及快速反向时先停后换向。SW1 `NETCONTROL_BTN` 单独验证配网触发和恢复出厂防误触。PA1 已不接 12 V 分压；供电跌落用外部仪表观察，固件只可依据驱动 `nFAULT` 或复位事件处理，不再按 MCU 电压采样值判断。
- 若取得小米 SDK，完成 BLE 配网、Wi-Fi 重连、`target-position` 下发和 `current-position` notify。

## Gate 2：功耗与射频 PoC

- 统计至少 30 分钟平均功耗，同时捕捉峰值电流。
- 分别测待机、联网和电机运行时的整板功耗；确认驱动器关闭输出及休眠时的电源电流。
- 首版测功耗时计入 12 V 与 3.3 V 两颗常亮电源灯；同时记录两灯支路电流和 GPIO 状态灯关闭后的输入功率。
- 在路由器 DTIM 1/3、弱信号、断网重连和云端频繁控制下分别测试。
- 电机运行时验证 3.3 V 纹波 `<100 mV`、Wi-Fi 不掉线、BLE 配网不受干扰。
- 天线附近放置最终电机、齿轮和外壳金属件，做最差姿态测试。

## Gate 3：v1 PCB

首块原理图和 PCB 样机可按 42CM02-1A 电机、DRV8434ARGER 裸芯片以及约 0.09 N·m 链轮运行扭矩目标推进；不等待开发板带电机测试。画板前仍须确认模组参考设计、G030 引脚、12 V 适配器及电机接口。现行 DC1 为 6.4/2.5 mm，[原厂图纸额定 DC 24 V、3 A](https://item.szlcsc.com/datasheet/DC-050-A250/43280632.html)；仍须以实测持续输入电流、热态、启动瞬态、接触温升及插头匹配核对整机方案。用户已删除 0.1 Ω 整机电流采样位，首版不恢复。v1 板保留 CN1 GH1.25 8P 调试口（UART/SWD/MCU 复位/`TUYA_CEN`）、关键电源测试点、可调相电流、驱动扭矩计数/故障信号、U7 GH1.25 4P 通用反馈扩展接口和可更换电机连接器。按[涂鸦烧录桥接方案](../hardware/schematic-review/tuya-programming-bridge.md)实测 CN1 经 G030 向 T1-3S 透传烧录及授权，并核对 CEN 复位时序、烧录工具波特率变化和写入校验；当前台架固件不具备该功能。实物验证至少覆盖上下端重复检测、`N_event−N_bottom` 偏移分布、不同帘重/速度/供电下误检漏检、正常链珠周期波动、卡阻注入、停止延迟和峰值拉力；任一关键判据不稳定时不能冻结自动校准方案。量产参数冻结前再以真实卷帘样机测运行扭矩、速度、温升、丢步和回零可靠性。

## 决策点

- **D0：主控技术栈。** 首版 STM32G030C8T6 + T1-3S 已确定；通信模组不得承担实时运动和安全逻辑。G030 资源与引脚冲突仍须随固件验证。
- **D1：未来米家通用模组/UART 路线是否获批？** 是：保留 STM32 并替换 `platform_tuya`；否：继续个人涂鸦版本或重新评估米家路线。
- **D2：MIoT 公版窗帘面板是否足够？** 是：不做 RN 扩展；否：评估扩展程序开发/审核成本。
- **D3：联网静息是否实测低于 100 mW？** 否：优化自动 light-sleep/DTIM，仍失败则与产品方重新定义“在线响应延迟”或功耗指标。
- **D4：低力矩上端回零能否可靠且不损伤机构？** 是：继续验证下端顿挫与真实最低点的关系并自动建立软件行程；否：调整设备内限扭、传动或电机/驱动，不加窗帘开关。下端扭矩计数判据若不可靠，重新研究设备内链轮运动反馈或机构方案；仍不可靠则暂不冻结自动校准方案，不以人工教行程替代。
- **D5：步进首选是否通过？** 用户优先采用步进电机；按实测拉珠力、速度、断电保持、上端到位信号、丢步、噪声和整套 BOM 验证。若关键要求无法满足，再比较直流减速备选；单独比较电机价格不足以定案。
