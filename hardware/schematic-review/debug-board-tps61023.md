# 调试板：TPS61023 3.3V 升 5V

2026-10-20 实板更新：用户确认 U1 安装方向反了，造成 VIN/EN 为3.3V而 VOUT 仅约13mV；已更换芯片、纠正方向，新一轮测试工作均正常。故障已修复，详见[故障及复测记录](../test-records/2026-10-20-debug-board-tps61023-repair.md)。下文保留2026-10-13的初始设计与检查快照，器件替换以之后的工程和审查记录为准。

2026-10-13 已在打开的 EasyEDA 工程 `涂鸦智能家居产品-窗帘开关` 中修改 `调试板 / Schematic3 / P1`。板 UUID：`82bb0b95aae32428`；页 UUID：`eecf0b63a633ebd0`。保留用户已放置的 U1，补齐其升压外围，保存到编辑器。

用途为给后续调试器接口提供 5V，设计负载至少 0.5A。输出网络为 `5V_DEBUG`，接口尚待用户补画。EN 接 `3V3`，输入有电即开启。

按 [TI 数据手册](https://www.ti.com/lit/ds/symlink/tps61023.pdf) 图 8-1 的 1µH、10µF、2×22µF、732kΩ/100kΩ 应用电路设置。标称输出 `0.6 × (1 + 732/100) = 4.992V`。电容的有效容量需计入直流偏压降容；后续若在接口侧增加大输出电容，重新检查补偿与启动。

网表确认：U1.1→BOOST_FB，U1.2/3→3V3，U1.4→GND，U1.5→BOOST_SW，U1.6→5V_DEBUG；L1 两端为 BOOST_SW/3V3；R3 为 5V_DEBUG/BOOST_FB；R4 为 BOOST_FB/GND。输入与输出电容分别跨接 3V3/GND、5V_DEBUG/GND。

新增器件的商城编号、数值与封装已从图元和网表读回确认；除 U1 外，改动前已有器件的逐脚网络未变。最终严格原理图 DRC 返回空数组（0 条问题）。已检查实际渲染的整页与局部图面；没有 PCB 布线或实物负载测试。

5V/0.5A、效率按 90% 估算时，3.3V 输入约需 0.84A。上游 3.3V 应在原有负载之外留出约 1A 供电余量。PCB 阶段将电感和电容靠近 U1，缩小 SW 与输出电容的开关电流回路，反馈走线避开 SW。
