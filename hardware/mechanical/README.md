# 外壳打印工程

[enclosure.3mf](enclosure.3mf) 来自用户确认的“零件5^main.3mf”，可用 Bambu Studio 打开。已清除设计者账户编号，仅保留 GitHub 署名 XJH-Jorhai；归档完整性校验通过，除设计者元数据外所有成员内容一致，模型几何、组件变换和打印配置未改动。

文件包含多个零件和打印盘。原配置为 Bambu Lab X1 Carbon 0.4 mm 喷嘴、0.20 mm Standard，并带有 PLA/PETG/ABS 耗材配置。这些是可修改的示例配置，不表示所有耗材均经过实物验证。打开后先检查每个对象的耗材分配、摆放与支撑，再按自己的设备切片；不直接发送到打印机。

实际使用材料、壁数、紧固件及装配顺序待作者补充。SolidWorks 装配源文件尚未完成依赖与元数据审查，暂不随候选发布；待 Pack and Go 和通用 STEP 到齐后补入。珠链轮的 OpenSCAD 源码及其上游许可另见相邻目录。
