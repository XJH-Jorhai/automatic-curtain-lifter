## 已实际使用的打印参数

| 项目 | 作者样机配置 |
|---|---|
| 打印机 | Bambu Lab X1 Carbon |
| 喷嘴 | 0.4 mm |
| 材料 | Polymaker PLA Pro，黑色 |
| 层高 | 0.2 mm |
| 壁圈数 | 2 圈（不是 2 mm 壁厚） |
| 电机/外壳固定 | M2.5 / M3 普通碳钢或不锈钢螺钉 |
| 安装位置与固定 | 用纳米胶粘贴在窗框和墙面 |

螺钉按实际装配自行选配，不提供固定长度与逐位置采购清单；根据连接处厚度和可用螺纹深度选择，避免顶到底或干涉运动件。装配关系参照提供的结构件和 3MF，本版不另提供装配图或逐步装配说明。填充与支撑可从打印工程检查并按设备调整。上述粘贴方式是作者样机做法，胶带型号、接触面积及长期承载尚未量化验证。

3MF 来自作者确认的“零件5^main.3mf”。已清除设计者账户编号，仅保留 XJH-Jorhai 署名；除设计者元数据外，归档各成员、几何、组件变换与打印配置保持不变。原文件含 PLA/PETG/ABS 多种耗材配置，这不代表都已实测。打开后以本页实际参数核对并调整各零件耗材、层高、壁圈数及支撑，再按自己的设备重新切片。
