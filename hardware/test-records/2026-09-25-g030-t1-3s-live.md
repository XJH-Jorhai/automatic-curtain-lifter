# G030C8T6 与 T1-3S 真实联调记录（2026-09-25）

## 结论

STM32G030C8T6 台架固件已经通过真实 T1-3S 模组完成串口初始化、AP 配网、云端连接、App 下发和状态回传。涂鸦智能 App 中的目标百分比与停止状态由用户确认显示正确。此结论只覆盖联网与 DP 通路，不代表电机、限位、位置测量或掉电恢复已经实现。

## 固件当前边界

- DP1 仅接受 `stop=1`；打开、关闭、继续均拒绝并报告停止。
- DP2 接受 0–100 的目标百分比，保存在 RAM；它不是实测位置。
- DP101 实际位置固定报告 0。重启后 DP2 目标恢复 0。
- 未连接电机驱动、限位、按键和 FRAM；尚未测试机械运动、故障保护、断电重连、BLE 配网、功耗和 MCU OTA。
- 本次使用的生成 SDK 快照早于 DP2 步长改为 1 的控制台修订。台架固件自身接受整数 0–100；正式固件仍应重新下载 XLS、产品协议和 SDK，并与修订后的 JSON 对齐。

## 后续工作

1. 冻结电机、限位、按键、故障和供电接线，再实现独立于涂鸦 DP 的运动安全层。
2. 用断电、模组重启、断网及重连场景验证状态一致性和掉电保持。
3. 根据完整引脚、定时器、Flash/RAM 与封装需求选择最终 MCU；当前 G030C8T6 是开发板，G031G6U6 是待评估候选，G071 是原先的余量方案。
