# 调试板 TPS61023 焊反故障与修复复测

日期：2026-10-20。记录依据：用户在本次对话中提供的实板测量及修复结果。

对象：窗帘开关工程的调试板，U1 为 TPS61023DRLR，3.3V 输入升压至 `5V_DEBUG`，用于无线调试器供电。

## 故障现象与测量

- 通过 GH 端子输入 3.3V。
- 用户测得 U1 VIN、EN 均为 3.3V，VOUT 约 13mV。
- 断电测量 `5V_DEBUG` 对 GND，用户报告开路/大于10kΩ，没有明显低阻短路。
- 当时未连接无线调试器，输出没有已知外部负载。

故障排查中重新核对了当前原理图及 PCB 的引脚网络：U1.1 为反馈，2/3 为 EN/VIN（3V3），4 为 GND，5 为电感开关节点，6 为输出；未发现该升压电路的基本接线错误。此核对不替代实板装配与通电验证。

## 确认原因与处理

用户确认故障原因为 **U1 芯片安装方向反了**，已更换芯片并纠正安装方向。

该次故障归因为装配方向错误；没有证据将其归因为升压拓扑或反馈参数错误。原芯片是否已损坏未单独确认，记录的处理方式为直接更换。

## 复测结果

用户反馈：**更换芯片后，新一轮测试工作均正常**。本次升压无输出故障已修复并完成用户复测。

修复后具体输出电压、负载电流、纹波、效率、温升及测试时长未提供；不将“复测正常”扩展为已完成5V/0.5A满载或长期可靠性验证。

后续装配按 PCB 焊盘编号与芯片1脚标识核对方向。
